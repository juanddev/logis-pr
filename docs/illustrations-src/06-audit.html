logis-pr --audit: cek dulu, aman nggak sih?

Penilaian cepat buat branch tiket, branch -dev, dan isi PR kamu, tanpa ngubah apa pun. Hasil akhirnya cuma dua: AMAN atau TIDAK AMAN.

AMAN · exit 0 Branch bersih

Isinya cuma commit tiket, -dev sinkron, dan PR di GitHub cocok.

Branch tiket LOGIS-3971 Commit tiket di luar production: 2 dbc1237 LOGIS-3971: tambah fitur b7b90d0 LOGIS-3971: update panduan [OK] Branch tiket: bersih Branch integrasi LOGIS-3971-dev → development Commit tiket : 2 sudah ada, 0 belum [OK] Branch integrasi LOGIS-3971-dev: bersih Commit di PR : 2 tiket, 0 baseline production [OK] Isi PR LOGIS-3971-dev → development: bersih PR di GitHub : #901 2 commit, 2 file [OK] AMAN: branch tiket & isi PR hanya berisi commit tiket (plus baseline production).

TIDAK AMAN · exit 1 Ada yang nyasar

Contoh: development pernah di-merge ke branch tiket. Kalau dipaksa PR, kerjaan orang lain ikut kebawa.

🌅 Sebelum mulai kerjaPastikan branch tiket masih bersih sebelum nambah commit.

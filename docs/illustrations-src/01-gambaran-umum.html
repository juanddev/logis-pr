logis-pr v2 · gambaran umum

Satu perintah, urusan review PR beres, dan PR-nya dijamin bersih

Nggak perlu lagi bolak-balik GitHub, Jira, dan Teams. Cukup jalankan ini dari branch tiket kamu:

~/SELOG_LOGIS_ServiceBilling (LOGIS-3939) % logis-pr -m "ver:1.0.0 tkt:LOGIS-3939 msg:tambah validasi"
Langkah 0: dicek dulu sebelum ngapa-ngapain. Kalau ada yang nggak beres, logis-pr langsung berhenti, dan belum ada apa pun yang diubah.
  • ✔ nggak ada merge yang setengah jalan
  • ✔ branch dari production
  • ✔ isinya cuma commit tiket kamu
  • ✔ nggak ada commit development / staging / tiket lain
  • ✔ nggak konflik
  • ✔ tiket Jira ketemu
1

Commit

Cuma perubahan file kamu. .DS_Store atau .env nggak ikut kecuali kamu izinkan. Daftar commit tiket ditunjukin dulu buat kamu cek.

konfirmasi [y/N]
2

Siapin LOGIS-XXXX-dev

Branch khusus buat development, dibikin dari production, isinya cherry-pick commit tiket kamu doang.

otomatis, tanpa force push
3

Bikin PR & cek isinya

-dev → development. Abis PR jadi, isinya dicek lagi di GitHub. Beda dikit aja? Stop.

reviewer: firdausnp
4

Geser tiket Jira

Dipindah sendiri step by step sampai Code Review. Misalnya To Do → In Progress → Code Review.

nggak pernah mundur
5

Kabarin di Teams

Pesan "Task: Review PR" masuk ke grup Oknum LOGis atas nama kamu. Ada preview dulu sebelum dikirim.

link PR ke-copy otomatis

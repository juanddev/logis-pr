logis-pr · kapan berhenti?

Kalau logis-pr berhenti, itu justru lagi nyelametin kamu

Semua pengecekan jalan sebelum commit. Jadi kalau berhenti, belum ada yang ke-push, belum ada PR, dan grup belum dapat pesan apa-apa.

Branch-nya bukan dari production

Branch kamu ternyata bawa commit yang cuma ada di development. Biasanya karena bikin branch dari development, atau pernah merge development ke branch kamu.

✖ BRANCH TIDAK DIBUAT DARI 'production' ✖ Branch 'feature/LOGIS-3942-b' membawa 1 commit ✖ yang hanya ada di 'development': ✖ 7cd7d06 fitur dev X
Benerinnya: bikin branch baru dari production, terus ambil commit kamu aja.
git switch production && git pull
git switch -c feature/LOGIS-3942-b-v2
git cherry-pick <sha-commit-kamu>

Bakal konflik sama target PR

Sebelum bikin PR, logis-pr nyobain merge dulu (simulasi, nggak ngubah file kamu). Kalau ada file yang bentrok, langsung stop. Exit code-nya 2.

✖ KONFLIK — PROSES DIHENTIKAN ✖ Merge feature/LOGIS-3943-c → development ✖ akan konflik di 1 file: ✖ src/app.ts
Benerinnya: sesuaiin perubahan kamu di file itu sama isi terbaru target. Cek bedanya pakai git diff origin/development...HEAD -- src/app.ts.
Jangan merge development ke branch kamu, nanti malah kena stop yang kiri.

Hotfix konflik cuma ke development?

Production-nya aman, tapi development udah beda jauh. Kirim dulu yang penting: logis-pr -b production -m "…" (atau pilih "production saja"). Habis itu bikin branch dari development, git cherry-pick commit hotfix-nya, beresin konfliknya di sana, lalu PR ke development.

Stop yang lain (gampang dibenerin, cek pakai logis-pr doctor):

gh belum loginJalanin gh auth login.
Lagi di production / developmentPindah ke branch kerja dulu.
Key tiket nggak ketemuNama branch harus ada LOGIS-1234, atau pakai -t.
Config belum lengkapJalanin logis-pr init.

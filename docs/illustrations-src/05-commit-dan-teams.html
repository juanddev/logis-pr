Yang di-commit aman, yang dikirim rapi

logis-pr nggak pernah git add --all. Jadi file nyasar nggak ikut ke PR, dan format pesan ke grup selalu seragam.

File mana yang ikut commit?

Contoh isi folder pas kamu jalanin logis-pr -m "…":

✓M README.mdikut, file lama yang kamu ubah
✓D src/old.tsikut, file yang kamu hapus
??? src/new-module.tsfile baru, ditanya dulu
??? .DS_Storefile baru, default nggak ikut
!?? .env.localditandai ⚠ mungkin rahasia
✕?? src/shared-libs/repo lain, nggak pernah ikut
Ada 3 file baru yang belum dilacak git:
  src/new-module.ts
  .DS_Store
  .env.local  ⚠ kemungkinan berisi rahasia!
? Ikutkan 3 file baru ini ke commit? (y/N)

Udah git add sendiri? Ya cuma itu yang di-commit.
Ada file baru yang memang mau ikut? Jawab y pas ditanya, atau tambahin -a.
Pakai -y? File baru otomatis nggak ikut, biar aman.
